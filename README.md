# Philadelphia Eagles Deep-Lore Trivia App 🦅

A high-difficulty, daily Philadelphia Eagles trivia game featuring a nickname welcome screen, 20-second timer, multiple choice options, post-selection feedback, spoiler-free text message sharing, offline audio synthesis, streak tracking, and zero-backend family/friends league leaderboards. Hostable on **GitHub Pages** without any API keys or servers.

---

## 🚀 How to Deploy on GitHub Pages (3 Easy Steps)

1. **Create a GitHub Repository**:
   - Go to [GitHub.com](https://github.com) and create a new public repository (e.g., `eagles-trivia`).

2. **Upload Files**:
   - Upload both `index.html` and `README.md` into the main branch of your repository.

3. **Enable GitHub Pages**:
   - Go to **Settings** > **Pages** inside your repository.
   - Under **Build and deployment**, select **Branch**: `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.

Your trivia application will be live at:
`https://<your-username>.github.io/<repository-name>/`
